# problem satatement

implement a C++ program to represent bus terminals as vertices and connections as weighted edges, 
where the weight is the travel time. Apply Dijkstra’s algorithm to find the minimum travel-time 
paths from a selected source terminal. The program should allow the user to select a different 
source terminal and recalculate the shortest distances (Modification A). It should also display 
the complete shortest path to each destination terminal, with the travel time of every hop and 
the total travel time, and not only the distance (Modification B).
