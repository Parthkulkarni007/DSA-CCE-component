# Objectives

1.To represent bus terminals and routes as a weighted graph using an adjacency matrix.

2.To apply Dijkstra’s algorithm to find the shortest travel time from a selected source.

3.To allow the user to select a different source terminal and recalculate all shortest distances without restarting the program.

4.To display the complete shortest path to every destination terminal, showing the travel time of each hop and the total time.
